# Components

Prefer existing template components before creating new ones.

Core components:

- cover slide;
- section slide;
- two-column slide;
- panel/card;
- metric tile;
- timeline/process;
- agenda/list;
- progress bar;
- slide counter;
- index/menu;
- print controls.

Rules:

- Use the component patterns already present in templates.
- Keep controls keyboard accessible.
- Keep PDF output clean, without navigation controls.
- Do not introduce decorative visual systems that are not in the template.
- **Every content slide pairs text/data with a visual on the opposite side.** Never
  leave a slide 100% text or 100% table/metrics with nothing visual next to it. Use,
  in this order of preference: a real image or diagram relevant to the content; an
  official Carbon pictogram from `organizations/ibm/assets/img/pictograms/`; an
  animated/decorative graphic already defined in the template's CSS (gradient blob,
  motion-grid, chart). Never invent or draw a new illustration by hand.
