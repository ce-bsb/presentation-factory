# Logo do Bob — pendente

Esta pasta está reservada para o logo/ícone oficial do Bob (IDE interna da IBM), a ser
enviado pelo usuário. Nenhum template referencia este asset ainda.

Quando o arquivo chegar:

1. Salve o SVG oficial aqui (ex.: `bob-logo.svg`).
2. Registre o asset em `organizations/ibm/assets/assets.yaml`, com `owner`, `purpose` e
   `use_when` (mesmo padrão dos demais logos).
3. Siga o mesmo procedimento canônico do logo IBM (`.bob/rules-presentation-factory/02-conteudo-e-design.md`):
   copie para `<workspace>/<slug>/assets/` em cada apresentação, nunca referencie
   direto da factory, nunca recrie com SVG manual/IA.

Não invente ou aproxime este logo enquanto o arquivo oficial não chegar.
