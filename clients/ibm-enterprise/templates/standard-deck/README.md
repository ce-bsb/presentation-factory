# IBM Standard — Workshop

Template de 7 slides para preparação de workshops, atualizado com a base visual Carbon v11 dos templates IBM. Preserva o conteúdo de exemplo, as tabelas e a checklist interativa.

Abra `index.html` diretamente ou copie a pasta inteira para um novo deck. O conteúdo é um exemplo e deve ser revisado antes de uso. As fontes IBM Plex são carregadas via Google Fonts.

CSS: `tools/template-assets/base.css` + `tools/template-assets/standard-deck.css`. JavaScript: `organizations/ibm/assets/js/deck.js`.

Execute `python3 tools/sync_template_assets.py` após editar essas fontes. O comando também atualiza `clients/ibm-enterprise/assets/css/styles.css`, usado pelo builder. Navegação por setas, indicadores, toque e teclado; modo de leitura responsivo e impressão de todos os slides.
